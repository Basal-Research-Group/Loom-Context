# 🚀 Guia de Inicio Rapido

## TL;DR

Instala Loom, corre `loom init .` en tu proyecto, y en <2 segundos tienes contexto arquitectonico listo para cualquier agente de IA.

---

## 📦 Instalacion

```bash
pip install loom-context
```

```bash
loom --version
# loom, version 0.2.0
```

> 💡 Si `loom` no esta en tu PATH, intenta `python3 -m loom_context.cli` o agrega `~/.local/bin` a tu PATH.

## 🎯 Contexto por Tarea (Bundle)

En vez del prompt completo (35KB), genera solo lo relevante para tu tarea:

```bash
loom bundle "refactorizar boundaries de core" . --stdout
```

```
# Bundle: refactorizar boundaries de core
**Project:** akana (react-native-expo, clean-architecture, hexagonal)

## Relevant Rules
- Layer boundary: core MUST NOT import from infrastructure

## Layer Boundaries
| Layer | MUST NOT import from |
|-------|---------------------|
| domain | infrastructure |
| core | infrastructure, presentation |
...

---
*Bundle generated by Loom v0.2.0 | strategy: heuristic | 6 sections*
```

> 📉 93% mas pequeno que el prompt completo.

Para guardar el bundle:
```bash
loom bundle "mi tarea" . --save
# Genera .context/bundles/mi-tarea/bundle.md + manifest.json
```

## 🤖 Exportar para tu Agente

```bash
loom export . --agent claude    # → .context/exports/CLAUDE.md
loom export . --agent cursor    # → .context/exports/.cursorrules
loom export . --agent codex     # → .context/exports/AGENTS.md
loom export . --agent generic   # → .context/exports/.loom-export.md
```

> 🔒 Los exports van a `.context/exports/` — nunca sobreescriben tus archivos.

## 🔁 Flujo de Trabajo Diario

```bash
# 1. Al empezar el dia
loom status .                              # ver estado
loom scan .                                # refrescar contexto

# 2. Antes de una tarea
loom bundle "mi tarea" . --stdout          # contexto enfocado
loom export . --agent claude               # exportar para tu agente

# 3. Durante el trabajo
loom decide "..." -r "..." -s architecture # registrar decisiones
loom log "progreso del dia" -p .           # anotar sesion

# 4. Al terminar
loom enrich .                              # re-auditar y persistir
loom handoff "mi tarea" . --save           # handoff para manana
```

## 📁 Que va en Git

| Carpeta | En git | Por que |
|---------|--------|---------|
| `.context/*.md, *.json` | ✅ Si | Es el valor de Loom — otros devs lo necesitan |
| `.context/exports/` | ❌ No | Se regenera con `loom export` |
| `.context/bundles/` | ❌ No | Se regenera con `loom bundle` |
| `.loom/` | ❌ No | Estado local por usuario |
