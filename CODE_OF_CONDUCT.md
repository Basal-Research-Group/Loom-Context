# Code of Conduct

## Our Standard

This project expects respectful, direct, and professional collaboration.

Examples of behavior that contribute to a healthy environment:

- discussing technical disagreements with evidence and clarity
- assuming good intent while still challenging weak reasoning
- giving actionable feedback instead of vague criticism
- respecting different experience levels and backgrounds

Examples of unacceptable behavior:

- harassment, intimidation, or personal attacks
- discriminatory language or exclusionary conduct
- bad-faith arguments, trolling, or repeated disruption
- publishing private information without permission

## Scope

This code of conduct applies in:

- GitHub issues and pull requests
- discussions around releases, security reports, and roadmap work
- any project communication spaces maintained by the project

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject comments, commits, issues, or contributions that violate this code of conduct.
