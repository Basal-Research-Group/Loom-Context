# Contributors

Loom-Context credits the people who build and maintain the project.

## Project Identity

- Loom-Context is maintained as a project-first open source effort.
- Public contributor credit is preserved through Git history, release notes, and
  project records.

## Contributors

- Contributors are credited through their commits and published contribution
  records.
- Individual names can be recognized in release notes, repository history, and
  the GitHub contributors graph.

If a contributor prefers a specific public identity, they should use that Git
identity consistently in commits and pull requests.
